System Scope

Production-oriented architecture for a large auto workshop. All major operational, inventory, sales, accounting, VAT, staff and management functions are connected.

CUSTOMER → VEHICLE → JOB CARD → PARTS + LABOUR + SERVICE → INVOICE → RECEIPT VENDOR → PO → GRN/PURCHASE RECEIPT → PURCHASE INVOICE → PAYABLE → PAYMENT PURCHASE → STOCK IN SALE / JOB PART ISSUE → STOCK OUT POSTED TRANSACTIONS → ACCOUNTING TAXABLE TRANSACTIONS → VAT ENGINE

1. Operating Modes

TOTAL MODE — Credit Only

Customer Master, Total/Credit Invoice, Customer Receipt, Credit Note, Debit Note, Customer Ledger, Outstanding, Aging, Statement.

Product, Vendor, Purchase, Stock, Warehouse, Workshop, Full Accounting, Payroll and Assets are unavailable. Hiding menus alone is not security.

FULL MODE — Complete ERP

All modules are available according to role and branch permission.

5. Inventory & Stock

Opening Stock

Quantity, cost, warehouse, approval.

Stock IN

Purchase/GRN, sales return, transfer in, positive adjustment.

Stock OUT

Sale, job parts issue, purchase return, transfer out, damage, scrap, negative adjustment.

Transfer

Branch/warehouse dispatch and receiving; each branch holds its own stock unless explicitly marked shared.

Inter-Branch Quick Request

Fast part request between the two branches when stock is short, approved and logged as a transfer without a full PO.

Stock Count

Physical vs system, variance, reason, approval.

Stock Ledger

Date, document, product, warehouse, IN, OUT, balance, cost, user.

Valuation

One consistent costing method (Weighted Average recommended for parts).

Reorder

Minimum/reorder levels, suggested quantity, preferred vendor.

Purchase/GRN → Stock + Sale → Stock - Job Parts Issue → Stock - Sales Return → Stock + Purchase Return → Stock - Transfer Out → Source - Transfer In → Destination + Adjustment → Approved Change

13. Security & Platform

Tenant Isolation

Every company/workshop is isolated and every record is tenant-scoped.

Roles

Owner, Branch Manager, Advisor/Salesman, Technician, Accountant — each with a defined permission set per module.

Branch Access

Users access assigned branches only unless authorized.

Permissions

View, create, edit, approve, post, cancel, reverse, print, export — each assigned per role per module (e.g. Technician: view/edit own job only; Advisor: create/edit estimate & invoice, no post/reverse accounting; Accountant: post/reverse accounting, no job-card edit; Branch Manager: approve + all module access within own branch; Owner: full access across branches).

Audit

User, time, branch, document, action, old/new value, reason.

Concurrency

Authoritative numbering, atomic posting, idempotency, duplicate protection.

Offline Sync

App works fully offline using local persisted cache; safe pending transaction sync to Firebase automatically the moment internet is available; clients do not control global numbering.

Backup

Auto local backup on app close, saved to a user-chosen folder (not fixed); periodic auto-upload to the user's own Google Drive as an additional safety layer; tested restore.

Performance

Pagination, query limits, indexes, summaries and branch/date filters.
